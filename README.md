# EZ Flo

A simple, responsive productivity dashboard built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a modern browser. No build step is required.

## Deploy to Netlify
1. Extract the ZIP.
2. Open https://app.netlify.com/drop and sign in.
3. Drag the extracted `ez-flo-redesign` folder onto the page.

## Included sections
- Welcome screen
- Home page with a simple workflow diagram
- Sidebar navigation
- Task Manager
- Study Planner
- Smart Notes
- GPA Calculator (4.0 grade-point inputs; verify your institution's scale)
- Progress Tracker
- Settings and local data reset
- FloBot help panel

## Important notes
- Data is stored in the browser's localStorage on the current device/browser. It does not sync across devices.
- FloBot is a small built-in help guide with predefined answers, not a live AI model.
- Live AI requires a secure serverless/backend endpoint. Never put private API keys in browser JavaScript.
